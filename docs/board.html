確かめてほしいこと — MapLibre + deck.gl / + Three.js / Navara あなたの番

おかしかったら、その番号を教えてください。

  1. cd web && pnpm dev → http://localhost:5173/?lon=139.7671&lat=35.6812&zoom=16&pitch=55&engine=maplibre-deckgl → 建物が青く (deck.gl で) 描かれ、一覧と右下のパネルは建物の上に出る。建物にマウスを乗せると吹き出しが出る
  2. 地形の欄に「deck.gl で地形を描きます…」。富士山 ?lon=138.7274&lat=35.3606&zoom=12&pitch=60&engine=maplibre-deckgl で起伏が出て、淡色地図が貼られている (鉄道などほかの行は地形の下に隠れるのは分かっている制約)
  3. バーで MapLibre に戻る → いつもの建物と地形に戻る
  4. ?lon=139.7671&lat=35.6812&zoom=16&pitch=55&engine=maplibre-three → 地図タイルの「＋ 追加」→ PLATEAU の「建物 (3D Tiles・公式配信)」を足す → 3D Tiles の建物が地面に乗っている (浮かない・沈まない。高さの基準は自動で合わせている)。 地形の欄に「高さの基準…読めなかった」が出ていたらその旨も教えてください
  5. 4 の続きでバーの Navara → 同じ場所・同じ向きで、淡色地図・地形・PLATEAU の 3D Tiles が描かれ、建物が地面に乗っている。 ドラッグで動かしてからバーで MapLibre に戻る → 動かした先の場所になる
  6. Navara からバーの Cesium へ直接替える → 同じ場所の Cesium になる (ヘッドレスでは重くて流せないので、ここだけ目で確かめてほしい)

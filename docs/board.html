  1. cd web && pnpm dev → http://localhost:5173/?lon=139.7671&lat=35.6812&zoom=16&pitch=50&engine=cesium を開く (Cesium で始まる)
  2. 地図タイルの「＋ 追加」→ 国土地理院「最適化ベクトルタイル」の「道路」を足す → 道路の線にマウスを乗せると吹き出し (「道路 › 道路中心線」・層・種別コード・出所・時点) が出る。線から外すと消える
  3. バーで MapLibre に戻り、地図タイルの「＋ 追加」→ PLATEAU の「建物 (3D Tiles・公式配信)」を足す → 行の2段目の「MapLibre では描けません (Cesium で描けます)」が行の枠に収まっている

見てほしい箇所 — ありふれていない部分

どこかで見たことのある書き方ではなく、このリポジトリ独自の判断が入っている所。 壊れたときに直せる人が要る順。項目を押すと、読み物 (コードの読みどころ) の該当の節が開く。 何のための仕組みか → どう解いたか → 要のコード、の順に、ファイルを開かずに読める。
